# LiDAR UAV V2 Results Index

This branch contains the complete LiDAR UAV V2 implementation and its
reproducible structure, correctness, efficiency, and learnability reports.

## Model baseline

- Model: `lidar_uav_v2`
- Current architecture: SBE-Lite + VQSA + EOOE spatial candidate model
- Training pipeline: sequence isolation + EQS + UQP
- Parameters: 1,045,352
- Archived Query-Causal learnability gate: PASS

## Binary artifacts

`initial_state.pt` and `final_smoke_state.pt` remain in the local output
directory but are intentionally excluded from Git. They are diagnostic
checkpoints, not formal trained model releases, and can be regenerated by
the historical commit `1271947`.

No formal V2 training checkpoint is claimed by these reports.
